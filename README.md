# Advanced Math Calculator

Browser-based calculator built with HTML, CSS, and vanilla JavaScript during the CodeAlpha internship.

## Features

- **Arithmetic and Scientific Operations**: Evaluates standard arithmetic expressions and mathematical functions directly in the browser.
- **Calculation History View**: Toggles between the active keypad (`calculator` view) and a logged history view (`history-page`) of previous evaluations.
- **Single-File Architecture**: All layout, styling, and JavaScript logic are bundled in `index.html` with zero external dependencies.

## Usage

Open `index.html` in any web browser, or run a local static server:

```bash
python -m http.server 8000
```
